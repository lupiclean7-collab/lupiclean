# Site LupiClean — publicação na Vercel

1. Crie a conta da Higiclean em vercel.com (login com GitHub ou e-mail).
2. Em "Add New → Project", escolha "Deploy" arrastando esta pasta `site-vercel` inteira
   (ou suba-a num repositório GitHub e importe). Não precisa de build: é HTML estático.
3. Nome do projeto sugerido: `lupiclean` → endereço `https://lupiclean.vercel.app`.
4. Se o endereço final for outro (domínio próprio ou outro nome), abra o `index.html` e troque
   `https://lupiclean.vercel.app` nas tags og:url, og:image e twitter:image (3 lugares).
5. Depois de publicar, abra `https://SEU-ENDERECO/og.jpg` no navegador para conferir a imagem e
   force a atualização do card do WhatsApp em developers.facebook.com/tools/debug.
